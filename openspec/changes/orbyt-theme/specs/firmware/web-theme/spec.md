# Spec Delta

## ADDED Requirements

### Requirement: Orbyt's mark
The web interface SHALL carry Orbyt's mark: at the head of every page, on the login page, and as the browser's icon for the router's pages, in the colors of the light or dark mode, loaded from the router itself.

#### Scenario: The mark on the pages
- **WHEN** the login page and a page after logging in are served
- **THEN** both show the mark, and both name the theme's own icon as the page's icon
